# Homebrew tap for Korev

```sh
brew install --cask thiagosalvatore/korev/korev
```

Korev updates itself after you install it. `brew uninstall --cask korev` removes the app. Add `--zap` to also remove Korev's settings, chats and caches. Your workspace worktrees in `~/korev/workspaces` are never removed.
